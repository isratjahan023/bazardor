# 🛒 বাজার দর — BazarDor

BazarDor is a Bengali grocery price tracking website that helps users explore daily prices, track price changes, and compare product prices across different markets.

## 🔗 Links

- Live Website: https://startling-queijadas-091480.netlify.app
- GitHub Repository: https://github.com/isratjahan023/bazardor

## 🛠️ Technologies Used

- Next.js App Router
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB Atlas
- React Hot Toast

## ✨ Features

1. Responsive design for mobile, tablet, and desktop.
2. Bengali product names, dates, prices, and units.
3. Infinite scrolling ticker showing product prices and daily changes.
4. Home sections displaying the top six price risers and fallers.
5. Category browsing with ascending and descending price sorting.
6. Protected product details with price summaries and market comparisons.
7. Email/password registration and login, plus Google and GitHub login.
8. User profile with a separate page to update the user's name.
9. Skeleton loaders and toast notifications.
10. Friendly 404 pages for unknown routes and invalid products or categories.

## 📡 Data Source

Product and category data are fetched from the given API:

## 📝 Price Notice

All displayed prices are indicative and may change depending on market conditions.
